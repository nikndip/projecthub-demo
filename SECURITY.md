# Безопасность

## Назначение и границы

ProjectHub Demo предназначено для локального технического знакомства. API не содержит аутентификации, разграничения ролей или полного комплекса защит закрытой CRM. Доступный клиент может создавать проекты и резервировать их бюджеты.

Не используйте demo для реальных финансовых операций и не размещайте в нём персональные данные, настоящие документы или секреты. Перед запуском в общей сети требуется отдельная оценка окружения и доступа. Демонстрационные реквизиты БД в Compose и `.env.example` предназначены для локального примера.

## Сообщить о проблеме

Не включайте секреты, реальные пользовательские данные или инструкции по эксплуатации ещё не исправленной уязвимости в публичный issue или PR.

Используйте [GitHub private vulnerability reporting](https://github.com/nikndip/projecthub-demo/security/advisories/new) (**Security → Report a vulnerability**) для приватного сообщения владельцу репозитория.

В приватном сообщении полезны затронутая версия или публичный commit, минимальный синтетический пример, условия воспроизведения и оценка последствий. Не проверяйте гипотезу на чужих системах или данных.

## Проверки и сопровождение

Команды проверок описаны в [README](README.md). Наличие workflow или этой политики не подтверждает отсутствие уязвимостей. Фиксированный срок ответа, отдельные поддерживаемые ветки и график обновлений пока не установлены; результаты проверки оцениваются для конкретного snapshot.
